Create self-signed key

openssl req -x509 -nodes -days 365 -newkey rsa:2048 -keyout nginx.key -out nginx.pem -config san.cnf -sha256

default_md = sha256

Vagrant setup

The following commands will require sudo, so maybe do a simple sudo call before this to cache the password/authentication.

wget -O - https://apt.releases.hashicorp.com/gpg | sudo gpg --dearmor -o /usr/share/keyrings/hashicorp-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/hashicorp-archive-keyring.gpg] https://apt.releases.hashicorp.com $(grep -oP '(?<=UBUNTU_CODENAME=).*' /etc/os-release || lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/hashicorp.list
sudo apt update && sudo apt install vagrant

I also need VirtualBox.

# 1. Update package lists
sudo apt update

# 2. Install necessary dependencies
sudo apt install build-essential dkms linux-headers-$(uname -r)

# 3. Add the official VirtualBox GPG key
wget -q https://www.virtualbox.org/download/oracle_vbox_2016.asc -O- | sudo apt-key add -

# 4. Add the VirtualBox repository (adjust 'focal' if on a different Ubuntu version)
echo "deb [arch=amd64] http://download.virtualbox.org/virtualbox/debian focal contrib" | sudo tee /etc/apt/sources.list.d/virtualbox.list
echo "deb [arch=intel64] http://download.virtualbox.org/virtualbox/debian focal contrib" | sudo tee /etc/apt/sources.list.d/virtualbox.list

# 5. Update again to include the new repo
sudo apt update

# 6. Install VirtualBox
sudo apt install virtualbox

Starting the server:
vagrant up

Destroy the server:
vagrant destroy -f
vagrant destroy <vmname> -f

Ping the server:
ansible testserver -m ping

Runa an (uptime) command on the server (module "command" is implied)
ansible testserver -a uptime

SSH details:
vagrant ssh-config

ssh to the server:
vagrant ssh
ssh vagrant@127.0.0.1 -p 2222 -i .vagrant/machines/default/virtualbox/private_key
(port or identity might be different)

Show all of the vagrant VMs on the machine:
vagrant global-status

Show all of the vagrant VMs on the machine, with a cache update:
vagrant global-status --prune

List VirtualBox VMs so I can delete one:
vboxmanage list vms
vboxmanage unregistervm "<vboxname>" --delete-all
